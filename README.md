# Moods Of Chatbot 🤖
An interactive AI-powered chatbot application built with **Streamlit**, **LangChain**, and the **Google Gemini API** that dynamically adjusts its responses and tone based on different conversational moods.

## 🚀 Live Demo
Click the badge above to launch and test the live application directly in your browser!

## 🛠️ Tech Stack & Dependencies
* **Frontend UI:** Streamlit
* **LLM Framework:** LangChain
* **AI Model:** Google Gemini (`google-genai`)
* **Configuration:** `python-dotenv`
